# Contributing to Awesome Coding Plans

Thanks for helping keep this resource accurate and up-to-date!

## How to Contribute

### Reporting Issues

- **Outdated pricing** — prices change frequently. If you spot one, open an issue with the correct price and a source link.
- **New plans** — know a plan we're missing? Suggest it with pricing details and a link.
- **Broken links** — if a link in this repo is dead, let us know.
- **Corrections** — model names, quota details, student offers — all fair game.

### Submitting Changes

1. **Fork** the repository
2. **Create a branch** (`fix/mimo-pricing`, `add/command-code`, etc.)
3. **Edit `plans.md`** with your changes
4. **Update the "Last updated" date** at the top of `plans.md`
5. **Submit a PR** with a clear description of what changed

### What to Include

- **Source links** for any pricing or model changes
- **Screenshots** are helpful but not required
- If adding a new plan, include: website, pricing, models, quota model, and key features

## Formatting Guidelines

- Follow the existing plan format: `## Plan Name` → `### Models` → `### Plans` → `### Key Features`
- Use the same table structure as neighboring plans
- Keep model names in backticks: `` `gpt-5.6-sol` ``
- Prices in USD unless the plan only bills in another currency
- Add anchor links to the Quick Comparison table at the top

## Adding a New Plan

When adding a new plan to `plans.md`:

1. Add it to the **Quick Comparison** table (in the right budget tier)
2. Add a full breakdown section with anchor link
3. Update relevant **comparison tables** (Under $10, Best Picks, etc.)
4. Update `README.md` if it's a notable addition

## Code of Conduct

- Be respectful in discussions
- No spam or self-promotion
- Keep discussions focused on improving the resource
