### Key Features
- **Agent-first IDE** — built for autonomous coding agents
- **Browser control** — agents can interact with web
- **Async interaction** — agents work in background
- **Multi-model** — Gemini, Claude, GPT-OSS in one platform
- **CLI included** — terminal-based agent interactions
- **SDK** — build custom agents
- **macOS, Linux, Windows** support
