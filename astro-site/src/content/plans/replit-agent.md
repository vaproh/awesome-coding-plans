# Replit Agent

**Website:** [replit.com/pricing](https://replit.com/pricing)

Cloud IDE with an agent that plans, builds, deploys, and hosts full applications from natural-language prompts. Credits cover agent effort, compute, and deployments.

### Plans

| Tier | Price | Includes |
|------|-------|----------|
| Starter | Free | Daily agent credits, limited AI, 1 published app, public projects |
| Core | $20/mo ($17-18/mo annual) | Full Agent, $20/mo usage credits toward frontier models, unlimited private workspaces, 5 collaborators, plan mode |
| Pro | $100/mo ($95/mo annual) | Up to 15 builders + 50 viewers, 10 parallel agents, $100/mo pooled credits with 1-month rollover, premium support, 28-day DB rollback |
| Enterprise | Custom | SSO/SAML, single-tenant, static IPs |

### Models

Frontier models (Claude and OpenAI class) consumed via effort-based checkpoints. Exact per-tier model list unpublished.

### Quotas

- Credits are effort-based: agent work, compute, and deployments draw from the monthly credit pool
- Overage is pay-as-you-go with no default cap
- Core includes $20/mo credits; Pro pools $100/mo with rollover

### Tools

- Agent (build/deploy from prompts), plan mode, Assistant
- Hosted cloud IDE, deployments, databases included
- No standalone API surface; everything runs in Replit's cloud

### Student offer

Roughly 50% off Core with a verified .edu email (about $10/mo), reported by third parties; not confirmed on replit.com. Verify before subscribing.
