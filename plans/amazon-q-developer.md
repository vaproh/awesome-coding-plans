# Amazon Q Developer

**Website:** [aws.amazon.com/q/developer/pricing](https://aws.amazon.com/q/developer/pricing/)

AWS's AI coding assistant with agentic coding, code transformation, and security scanning, deeply integrated with AWS tooling.

### Plans

| Tier | Price | Includes |
|------|-------|----------|
| Free | $0 | IDE plugins + CLI, 50 agentic requests/mo, 1,000 LOC/mo Java transformation, code suggestions, security scans, reference tracking |
| Pro | $19/user/mo | Higher agentic request limits, 4,000 LOC/mo pooled Java/.NET transformations (overage $0.003/LOC), IAM Identity Center, admin dashboards, IP indemnity, data opt-out |

### Models

Latest Claude models served through AWS.

### Quotas

- Free: 50 agentic requests/month, 1,000 LOC/month Java transformation
- Pro: 1,000 agentic requests (chat interactions)/month, 4,000 LOC/month/user pooled at account level

### Tools

- IDE plugins: VS Code, JetBrains, Visual Studio
- CLI and agentic coding (Q CLI agent)
- No general API on the subscription; Amazon Bedrock is the per-token API path

No student discount documented.
