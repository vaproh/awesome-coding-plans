# Fireworks Fire Pass

**Website:** [app.fireworks.ai/fire-pass](https://app.fireworks.ai/fire-pass)

Flat-rate access to Fireworks' inference platform with no per-token charges on select models.

### Models

| Model | Notes |
|-------|-------|
| `kimi-k2.6-turbo` | No per-token charges (included in Pass) |
| Other models | Available at per-token rates |

### Plans

| Tier | Price | Notes |
|------|-------|-------|
| **Fire Pass** | $7/wk ($28/mo) | No per-token charges for kimi-k2.6-turbo |

### Key Features
- **Flat rate on select models** — no token metering
- **Fast inference** — Fireworks' optimized infrastructure
- **Pay-per-use** for other models beyond included ones
