# Ollama Pro

**Website:** [ollama.com/pricing](https://ollama.com/pricing)

Run and access frontier models locally with cloud assistance. Pro includes $60 of monthly usage credits.

### Models

Access to open-weight models including:
- Kimi K3, K2.7 Code, K2.6, DeepSeek V4 Flash/Pro, GLM-5.3/5.2/5.1, Qwen3.5, MiniMax M3/M2.7, Gemma4, GPT-OSS, Nemotron, Mistral Large 3, and more

### Plans

| Tier | Price | Included Usage | Notes |
|------|-------|----------------|-------|
| **Free** | $0 | Starter credits | Limited models, add credits to unlock all |
| **Pro** | $20/mo ($16.67/yr) | $60/mo usage credits | Access to pro models, multiple concurrent |
| **Max** | $100/mo | $300/mo usage credits | 10 concurrent requests, early access |
| **Team** | $500/mo | $1,000/mo shared credits | Unlimited users, centralized billing |
| **Enterprise** | Custom | Custom | Model access controls, cost budgets |

### Key Features
- **Local + cloud hybrid** — run models locally, fall back to cloud
- **No per-token billing on plan** — flat monthly fee with included credits
- **Native weights** — models run at original quality
- **Works with OpenAI-compatible API** — drop-in replacement
- **Unused credits do not roll over** — refresh monthly
