# Qoder Pro

**Website:** [qoder.com/pricing](https://qoder.com/pricing)

AI coding agent by Alibaba Cloud. Supports agentic workflows, Quest Mode, and Repo Wiki.

### Plans

| Tier | Price | Credits | Notes |
|------|-------|---------|-------|
| **Free** | $0 | 2-week trial + 300 credits | Limited completions, BYOK |
| **Pro** | $20/mo | 2,000 | + 2,000 bonus on first purchase |
| **Pro+** | $60/mo | 6,000 | + 6,000 bonus on first purchase |
| **Ultra** | $200/mo | 20,000 | + 1,000 bonus on renewals |
| **Credit Pack** | $20 | 1,500 | Add-on, 1 month validity |

### Key Features
- **Quest Mode** — autonomous task completion
- **Repo Wiki** — codebase knowledge base
- **Expert team mode** — multi-model collaboration
- **BYOK supported** — bring your own API key
- **Monthly credits** — refresh each cycle, no rollover
